## 用嘉立创 EDA 专业版打开

1. 安装 [嘉立创 EDA 专业版](https://lceda.cn/page/download)。
2. 菜单：**文件 → 导入 → EDA 专业版工程（.epro）**，选中本目录下的 `.epro`。
3. 工程名：**STM32学习板**。原理图 3 页（主控 / 电源 / 接口），PCB 一块。

标准版无法直接打开 `.epro`。不要用解压软件当普通压缩包改里面的散列文件名，容易把工程弄坏。

## 导出生产文件

在专业版中打开 PCB 后：

- **制造 → PCB 下单 / 导出 Gerber**：嘉立创打样
- **制造 → 导出 BOM**：SMT 贴片
- **制造 → 导出坐标文件**：钢网与贴片

推荐工艺：两层板、FR-4、板厚 1.6 mm、有铅/无铅喷锡均可、过孔盖油。板框约 **60 mm × 80 mm**，四角 R3，四个 M3 安装孔。
