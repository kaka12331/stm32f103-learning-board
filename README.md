# STM32F103RCT6 学习板

**仓库：`stm32f103-learning-board`**

从零画的一块 **STM32 入门学习板**，嘉立创 EDA 专业版工程。面向单片机课、电赛预备和日常外设实验：Type-C 供电、Type-C 串口自动下载、1.8 寸 SPI 彩屏、按键、电位器、蜂鸣器、RTC 纽扣电池和常用 2.54 / XH 接口。

主控是 **STM32F103RCT6**（Cortex-M3，72 MHz，256 KB Flash，LQFP-64）。板框约 **60 mm × 80 mm**，双层板，四角 R3，四个 M3 安装孔。

---

## 这块板是干什么的

常见最小系统只有 SWD 和几个 LED，外设一多就要飞线。这块板把入门阶段最常用的东西画在一起：

- 一根 Type-C 充电线就能供电（带 CC 识别，普通手机充电器可以用）
- 另一根 Type-C 接电脑，CH340C 自动下载，不必每次按 BOOT/复位
- 板载 1.8 寸 SPI 彩屏，不用再插杜邦线对色
- 蜂鸣器、用户按键、电位器、指示灯，GPIO / ADC / 定时器实验直接做
- 排针和 XH 座引出 I2C、SPI、UART、电源，接模块不用焊排针飞线

原理图按功能拆成三页：**主控 / 电源 / 接口**，方便对照着学。

## 功能一览

| 模块 | 方案 | 说明 |
| --- | --- | --- |
| **主控** | STM32F103RCT6 | 256 KB Flash，USB/CAN/高级定时器都在芯片里，引脚比 C8T6 宽裕 |
| **高速晶振** | 8 MHz，3225 | HSE，负载 18 pF |
| **低速晶振** | 32.768 kHz，3215 | LSE，给 RTC |
| **RTC 电池** | CR1220 + BAT54C | 掉电保持日历时钟 |
| **供电 Type-C** | USB1 + CH213K | CC 识别 5 V，再经 AMS1117-3.3 给 MCU |
| **LDO** | AMS1117-3.3 | 5 V → 3.3 V，1 A |
| **串口 Type-C** | USB2 + CH340C | USB 转 UART，自动下载电路 |
| **复位** | TS-1101 轻触 | 独立复位键 |
| **启动模式** | 2.54 跳线 | BOOT0 / BOOT1 选择 |
| **彩屏** | 1.8" 128×160 SPI | 板载贴装，少接线 |
| **蜂鸣器** | MLT-5020 无源 4 kHz | SS8050 驱动 |
| **电位器** | 3362P 10 kΩ | ADC 练习 |
| **用户按键** | 两颗 6×6 | 外部中断 / 扫描 |
| **LED** | 0603 红 + 绿 | 电源 / 用户指示 |
| **下载口** | SWD 排针 | ST-Link / J-Link 备用 |
| **扩展** | 2.54 排针 + XH2.54 | GPIO、I2C、SPI、+5 V |

I2C 上拉电阻设计成**可选焊接**：当口当 I2C 用时再焊，当普通串口/GPIO 用时不要焊，原理图上有文字说明。

## 第一次上电

1. **只插 USB1（供电口）**，不要同时乱插未确认的口。
2. 3.3 V 指示灯应亮。万用表量 AMS1117 输出，应在 3.2～3.4 V。
3. 插 USB2 到电脑，设备管理器应出现 CH340 串口。缺驱动时到 [沁恒](https://www.wch.cn/) 下 CH340 驱动。
4. Keil / STM32CubeProgrammer 用串口下载：115200，8N1。自动下载正常时，点 Download 会自己复位进 ISP，不必按 BOOT。
5. 自动下载失败时：BOOT0 跳到 1，按复位，用 ISP 工具下载；或用 SWD 口接 ST-Link。
6. 再跑点灯、串口、ADC 电位器、蜂鸣器、SPI 屏。屏的脚位以原理图第 3 页「SPI显示屏」为准。

**注意：** 这是学习板，没有理想二极管和完整的 USB PD 协商，不要从两个 Type-C 同时灌大电流。电机、舵机从 XH / +5 V 座供电时，地要共地，电流不要倒灌进 LDO。

## 建议的实验顺序

1. GPIO 闪灯、按键消抖  
2. USART 打印，确认自动下载  
3. SysTick / TIM 延时与 PWM（蜂鸣器）  
4. ADC 读电位器  
5. SPI 刷 1.8 寸屏  
6. I2C 外挂 OLED / IMU（焊上拉）  
7. RTC + CR1220 掉电走时  
8. 片上 USB / CAN（芯片支持，板级是否引出以原理图为准）

固件不在本仓库。任意 F103 标准库或 HAL 工程，芯片选 **STM32F103RC**，外部高速晶振 **8 MHz**。

## 设计说明（为什么这样画）

- **RCT6 而不是 C8T6**：Flash 256 KB，定时器和 IO 够后面加屏、总线和作业工程，避免 C8 64 KB 不够用。
- **双 Type-C**：供电和串口分开，电脑口只走数据，充电器口只走电，减少倒灌。
- **CH213K**：很多充电头不认“悬空 CC”，没有这颗芯片会 0 V 或只给到 0.5 A 不稳定。
- **CH340C 自动下载**：DTR/RTS 经三极管拉复位/BOOT0，Keil 一键下载，适合课堂。
- **LDO 而不是开关电源**：噪声小、好焊、好测；学习板电流不大，热耗可接受。
- **I2C 上拉可选**：同一组脚既能当 I2C 也能当 UART/GPIO，避免上拉干扰。
- **屏直接上板**：少插排线，教室里不容易松。

## 已知限制

- 默认固件未随仓库提供，需要自己写或移植。
- 未做 USB 设备口引出（F103 的 USB 外设是否接到 Type-C 请看原理图，当前 Type-C 数据口走的是 CH340）。
- 没有板载 ST-Link，SWD 需外接调试器。
- 3.3 V 由线性稳压器提供，大电流外设请走 5 V 座，不要全从 AMS1117 抽。
- 器件库里可能有未放置封装（例如部分电源方案器件），以原理图位号为准。
